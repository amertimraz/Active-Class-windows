# 🎛️ نظام الإعدادات - Active Class

## 📋 نظرة عامة

تم تنفيذ نظام إعدادات شامل لتطبيق Active Class يوفر:
- واجهة إعدادات أنيقة على شكل modal
- حفظ الإعدادات في قاعدة بيانات SQLite
- تطبيق فوري للتغييرات دون إعادة تشغيل
- دعم الثيم الداكن والفاتح
- دعم اللغتين العربية والإنجليزية

## 🗂️ الملفات المضافة/المحدثة

### ملفات الواجهة الأمامية:
- `public/pages/settings.html` - صفحة الإعدادات الرئيسية
- `public/pages/settings.css` - تنسيقات الإعدادات
- `public/pages/settings.js` - منطق الإعدادات والتفاعل

### ملفات الخادم:
- `server/sqlite.js` - إضافة جدول settings وإعدادات افتراضية
- `server/server.js` - إضافة API endpoints للإعدادات

### ملفات محدثة:
- `public/router.js` - إضافة دعم modal الإعدادات وتطبيق الثيم
- `public/styles.css` - إضافة متغيرات الثيم الداكن
- `public/index.html` - إضافة زر الإعدادات

## 🎨 التبويبات المتاحة

### 1️⃣ قاعدة البيانات والنسخ الاحتياطي
- **مسار قاعدة البيانات**: عرض وتعديل مكان حفظ قاعدة البيانات
- **النسخ الاحتياطي**: إنشاء نسخة احتياطية فورية
- **الاستعادة**: استعادة من نسخة احتياطية
- **النسخ التلقائي**: تفعيل النسخ الاحتياطي عند الإغلاق

### 2️⃣ المظهر واللغة
- **اللغة**: التبديل بين العربية 🇪🇬 والإنجليزية 🇬🇧
- **الثيم**: التبديل بين الفاتح 🌞 والداكن 🌙
- **إعادة الضبط**: إعادة جميع الإعدادات للافتراضية

### 3️⃣ واجهة النظام والتحكم
- **أزرار الحذف**: إظهار/إخفاء أزرار حذف الطلاب والمجموعات
- **الرسوم المتحركة**: تفعيل/تعطيل الانيميشن
- **الإشعارات**: تفعيل/تعطيل الإشعارات

### 4️⃣ حول البرنامج
- **معلومات التطبيق**: الاسم والإصدار
- **معلومات المطور**: تفاصيل التطوير
- **الروابط المفيدة**: الدعم والتحديثات

## 🔧 API Endpoints

### GET `/api/settings`
استرجاع جميع الإعدادات
```json
[
  {
    "key": "theme",
    "value": "light",
    "created_at": "2025-01-27 10:00:00",
    "updated_at": "2025-01-27 10:00:00"
  }
]
```

### POST `/api/settings`
إنشاء أو تحديث إعداد
```json
{
  "key": "theme",
  "value": "dark"
}
```

### GET `/api/settings/:key`
استرجاع إعداد محدد

### PUT `/api/settings/:key`
تحديث إعداد محدد

### DELETE `/api/settings/:key`
حذف إعداد محدد

### POST `/api/backup`
إنشاء نسخة احتياطية

### POST `/api/restore`
استعادة من نسخة احتياطية

## 🎯 الإعدادات الافتراضية

```javascript
{
  language: 'ar',                    // اللغة الافتراضية
  theme: 'light',                    // الثيم الافتراضي
  dbPath: './data/activeclass.db',   // مسار قاعدة البيانات
  backupPath: '',                    // مسار النسخ الاحتياطي
  autoBackup: false,                 // النسخ التلقائي
  showDeleteAllStudents: false,      // إظهار زر حذف الطلاب
  showDeleteAllGroups: false,        // إظهار زر حذف المجموعات
  showAnimations: true,              // الرسوم المتحركة
  showNotifications: true            // الإشعارات
}
```

## 🚀 كيفية الاستخدام

### 1. فتح الإعدادات
- انقر على زر الإعدادات ⚙️ في شريط الأدوات العلوي
- أو استخدم الاختصار المناسب

### 2. تغيير الثيم
```javascript
// في settings.js
async function applyTheme(theme) {
  document.documentElement.setAttribute('data-theme', theme);
  await saveSettings('theme', theme);
}
```

### 3. تغيير اللغة
```javascript
// في settings.js
async function applyLanguage(language) {
  const isArabic = language === 'ar';
  document.documentElement.lang = language;
  document.documentElement.dir = isArabic ? 'rtl' : 'ltr';
  await saveSettings('language', language);
}
```

## 🐛 استكشاف الأخطاء

### مشاكل شائعة:

1. **الثيم لا يتغير**:
   - تحقق من وجود متغيرات CSS
   - تأكد من تطبيق `data-theme` على `html`

2. **الإعدادات لا تُحفظ**:
   - تحقق من اتصال قاعدة البيانات
   - راجع console للأخطاء

3. **Modal لا يفتح**:
   - تأكد من تحميل ملفات CSS و JS
   - راجع أخطاء JavaScript
