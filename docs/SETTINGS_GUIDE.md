## 🔧 الوظائف البرمجية

### ✅ API Endpoints:
- `GET /api/settings` - استرجاع جميع الإعدادات
- `POST /api/settings` - إنشاء/تحديث إعداد
- `GET /api/settings/:key` - استرجاع إعداد محدد
- `PUT /api/settings/:key` - تحديث إعداد محدد
- `DELETE /api/settings/:key` - حذف إعداد محدد
- `POST /api/backup` - إنشاء نسخة احتياطية
- `POST /api/restore` - استرجاع نسخة احتياطية

## 🧪 كيفية الاختبار

### 1. اختبار سريع:
1. شغل الخادم: `double-click run-test.bat`
2. افتح: http://localhost:5000/test-settings
3. اختبر جميع الوظائف من الصفحة

### 2. اختبار من التطبيق الرئيسي:
1. افتح: http://localhost:5000
2. انقر على زر الإعدادات ⚙️ في الشريط العلوي
3. جرب جميع التبويبات والوظائف

### 3. اختبار قاعدة البيانات:
```bash
# تحقق من وجود الجدول
sqlite3 data/activeclass.db ".schema settings"

# عرض الإعدادات المحفوظة
sqlite3 data/activeclass.db "SELECT * FROM settings;"
```

## 🎯 الإعدادات المتاحة

```javascript
{
  language: 'ar',                    // اللغة: ar/en
  theme: 'light',                    // الثيم: light/dark
  dbPath: './data/activeclass.db',   // مسار قاعدة البيانات
  backupPath: '',                    // مسار النسخ الاحتياطي
  autoBackup: false,                 // النسخ التلقائي
  showDeleteAllStudents: false,      // إظهار زر حذف الطلاب
  showDeleteAllGroups: false,        // إظهار زر حذف المجموعات
  showAnimations: true,              // الرسوم المتحركة
  showNotifications: true            // الإشعارات
}
```
