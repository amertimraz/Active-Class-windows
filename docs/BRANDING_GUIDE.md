# دليل هوية Active Class

## التغييرات المطبقة

تم تحديث هوية البرنامج من "إدارة الفصل" إلى "Active Class" في الملفات التالية:

### 1. الملفات المحدثة
- ✅ `package.json` - تغيير اسم المشروع والوصف
- ✅ `main.js` - تغيير عنوان النافذة وإضافة مسار الأيقونة
- ✅ `public/index.html` - تغيير العنوان والهيدر والفوتر
- ✅ `public/styles.css` - إضافة تنسيق للأيقونة
- ✅ `server/server.js` - تحديث رسالة السيرفر

### 2. المجلدات المنشأة
- ✅ `assets/` - لأيقونة التطبيق الرئيسي
- ✅ `public/assets/` - لأيقونة واجهة الويب

## كيفية إضافة الأيقونة

### الخطوة 1: تحضير ملف الأيقونة
- **الاسم**: `icon.gif`
- **الحجم المقترح**: 256x256 بكسل أو أكبر
- **الصيغة**: GIF (يدعم الحركة)
- **الخلفية**: شفافة (مفضل)

### الخطوة 2: وضع الملفات
```
نسخ ملف icon.gif إلى:
├── assets/icon.gif          (للتطبيق الرئيسي)
└── public/assets/icon.gif   (لواجهة الويب)
```

### الخطوة 3: اختبار التطبيق
```bash
npm start
```

## صيغ أيقونات أخرى مدعومة

إذا كنت تريد استخدام صيغة أخرى غير GIF:

### PNG (الأكثر شيوعاً)
```javascript
// في main.js
icon: path.join(__dirname, 'assets', 'icon.png')
```
```html
<!-- في index.html -->
<img src="/assets/icon.png" alt="Active Class" class="brand-logo">
```

### ICO (مخصص لـ Windows)
```javascript
// في main.js
icon: path.join(__dirname, 'assets', 'icon.ico')
```

### SVG (متجه قابل للتكبير)
```javascript
// في main.js
icon: path.join(__dirname, 'assets', 'icon.svg')
```
```html
<!-- في index.html -->
<img src="/assets/icon.svg" alt="Active Class" class="brand-logo">
```

## ملاحظات مهمة

1. **إذا لم تضع الأيقونة**: البرنامج سيعمل بدون أيقونة مخصصة
2. **أحجام متعددة**: يمكنك إنشاء أحجام مختلفة (16x16, 32x32, 64x64, 128x128, 256x256)
3. **التوافق**: GIF يعمل على جميع المنصات ويدعم الحركة
4. **الأداء**: الأيقونات الصغيرة تحمل أسرع

## استكشاف الأخطاء

### الأيقونة لا تظهر في التطبيق
- تأكد من وجود الملف في `assets/icon.gif`
- تأكد من صحة اسم الملف (حساس للأحرف الكبيرة/الصغيرة)

### الأيقونة لا تظهر في الويب
- تأكد من وجود الملف في `public/assets/icon.gif`
- افتح Developer Tools وتحقق من تحميل الملف

### رسالة خطأ عند التشغيل
- تأكد من أن مجلد `assets` موجود
- يمكنك حذف سطر الأيقونة من `main.js` مؤقتاً للاختبار
